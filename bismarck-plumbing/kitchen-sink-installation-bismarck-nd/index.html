    How We Install Kitchen Sinks in Bismarck, ND: Style by Style

    Farmhouse Sink Installation in Bismarck, ND

    A fireclay apron sink sits on a frame inside the cabinet, not on the countertop. A lot of them drain toward the back, so the trap layout has to match.

    Farmhouse Sink Plumbing in Bismarck, ND

    Fireclay and cast iron farmhouse sinks can weigh well over 100 pounds empty, before a single drop of water goes in. We build a support frame inside the cabinet and set the sink level before the counter is installed. A deep bowl means a lower trap. We plan the drain for that depth from the start.

    Apron-Front Sinks in Bismarck, ND

    Apron sinks need a cabinet cut to fit the front panel, and the sink has to be in place before the counter is templated. We set the sink and frame early, so the fabricator measures from the actual bowl instead of a spec sheet. It prevents a crooked reveal. Cast iron versions can top 150 pounds, so we bring two people.

    Composite Sink Installation in Bismarck

    Granite and quartz composite sinks resist scratches on the surface but can chip at the drain hole if a strainer is overtightened. Hand tight comes first. Most composite brands want silicone rather than putty under the strainer because putty can stain them, so we go by the maker's instructions.

    Stainless Sinks With Sound Pads in Bismarck

    Cheap stainless bowls are noisy when dishes hit them or the disposal runs. Better sinks come with rubber pads and an undercoating, and if yours does not, we can add a coat of spray undercoating before we set it. It is a small upgrade. After the sink is in place the underside is hard to get at, which is why we do it while the bowl is still sitting out.

    Workstation Sink Installation in Bismarck, ND

    Workstation sinks have a ledge for cutting boards, colanders and drying racks, and most are single deep bowls with an offset drain. We plan the trap around that offset drain so the disposal fits and the cabinet keeps usable space on one side. Faucet reach matters too.

    Sink and Disposal Installed Together in Bismarck, ND

    A new sink is the cheapest time to add a disposal. We mount the disposal on the new flange, set the trap height for its outlet, and knock out the dishwasher plug so the hose has somewhere to go. Power is a separate question. We check for a switched outlet in the cabinet.
