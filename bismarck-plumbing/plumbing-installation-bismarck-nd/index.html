    Natural Gas and Propane Lines in Bismarck, ND

    Natural gas and propane run at different pressures, and the pipe sizing changes with them. Our licensed plumbers size each run from the appliance BTU ratings and the developed length, then choose black iron or CSST to suit the route. CSST must be bonded. Skip the bond and a nearby lightning strike can arc through the tubing, which is one more reason gas work is not a weekend project.

    Sewage Ejector Pump Installation in Bismarck, ND

    A basement bathroom sits below the sewer line, so gravity cannot carry the waste out. The fix is a sealed basin with an ejector pump that lifts waste to the main. We size the pump and basin to the fixtures it serves, vent the basin to code, and put a check valve and a full-port shutoff on the discharge so the pump can be pulled for service. We usually install Liberty or Zoeller pumps.
